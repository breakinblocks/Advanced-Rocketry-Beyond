# Advanced Rocketry Beyond

Advanced Rocketry for Minecraft 1.21.1 on NeoForge. Build rockets, explore
generated star systems, set up space stations and run industry in orbit.

## Features

- **Rockets:** assemble rockets from engines, tanks, seats and guidance on a
  launch pad, fuel them, and fly between planets, moons and stations. Uncrewed
  rockets run asteroid mining and gas giant collection missions.
- **Planets:** star systems with planet and moon dimensions, each with its own
  gravity, atmosphere, temperature, sky, biomes, craters, volcanoes, geodes and
  ores.
- **Life support:** modular space suits, oxygen tanks, jetpacks and visors.
  Oxygen vents pressurize sealed rooms, and airtight doors keep the air in.
- **Space stations:** pack a build into a module, launch it to orbit, and grow
  it with docking ports. Stations can warp between planets and have gravity,
  altitude and orientation controls. Space elevators connect them to the ground.
- **Satellites:** solar power beamed to microwave receivers, research data,
  ore mapping and biome changing.
- **Machines:** ten processing multiblocks (lathe, rolling machine,
  crystallizer, electrolyzer, chemical reactor, cutting machine, precision
  assembler, precision laser etcher, centrifuge, electric arc furnace), plus the
  orbital laser drill, observatory, railgun, atmosphere terraformer, black hole
  generator, area gravity controller and more.
- **Automation:** energy cables, fluid pipes and item conduits with per-face
  modes, redstone control and filters.
- **Holographic projector:** previews any multiblock in the world, one layer at a
  time, and lists the materials it needs.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.209 or newer
- Optional: [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) for recipe
  views, [Jade](https://www.curseforge.com/minecraft/mc-mods/jade) for machine
  status tooltips, and [GuideME](https://www.curseforge.com/minecraft/mc-mods/guideme)
  for the in-game Field Guide.

## Customizing

Planets, stars, asteroids, ore profiles, multiblock layouts, processing recipes,
tags and data maps all load from datapacks. See [DATAPACKS.md](DATAPACKS.md).
Gameplay settings are in the server config.

## Building

Requires Java 21.

```
./gradlew build
```
