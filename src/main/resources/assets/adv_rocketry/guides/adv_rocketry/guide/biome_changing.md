# Biome-changing satellites

Deploy a biome-changing satellite and retain its linked remote. Sample a biome with the remote and apply it to a target area.

The satellite changes a **32×32 area** in powered, persistent batches. Allow time and provide enough satellite power.

Biome changes do not directly replace atmosphere work. Use the [Atmosphere Terraformer](atmosphere_terraformer.md) to adjust pressure.
