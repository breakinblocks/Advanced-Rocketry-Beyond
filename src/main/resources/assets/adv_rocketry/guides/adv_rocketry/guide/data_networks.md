# Research data networks

Distance, mass and composition are separate data types. One cannot substitute for another.

Data Buses serve compatible research machinery. Item Data Storage units carry collected data between terminals and machines, and also serve as satellite storage components.

Use a Linker on two Wireless Transceivers to pair them. Put each beside a compatible bus or machine. Nodes exchange typed data and retain **100 units per channel**. Keep both ends loaded.

Collect data from [satellites](satellite_builder.md), then use it in the [Observatory](observatory.md), [Astrobody Data Processor](astrobody_data_processor.md) or [warp research](warp_travel.md).
