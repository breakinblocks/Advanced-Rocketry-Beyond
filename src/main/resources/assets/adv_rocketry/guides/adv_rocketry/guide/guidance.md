# Guidance and return trips

The Guidance Computer holds destination information. A programmed Planet ID Chip selects a planet; a Station ID Chip identifies a station. Rocket controls offer available station landing pads.

Crouch-use a Station ID Chip to manage named return locations for each planet. Its protected **Last** entry tracks the departure point. Keep a programmed chip accessible when managing several bases.

Landing Pads register named station landing spots. A programmed Linker can override the departure rocket's return coordinates at a pad.

A rocket descending onto lava creates a Landing Float beneath its footprint for emergency support. Do not rely on that as a substitute for choosing a safe landing site.

After landing, confirm the return destination and fuel. Destinations are normally visible, but servers can require [discovery](warp_travel.md).
