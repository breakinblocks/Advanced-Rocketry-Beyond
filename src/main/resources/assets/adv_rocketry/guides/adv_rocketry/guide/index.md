# Advanced Rocketry

Build a workshop, prepare life support, then leave Earth. This field guide takes you from your first plate to an interplanetary station.

Craft this book from **a book, iron ingot, copper ingot and redstone** in any arrangement. Search by topic or use GuideME's item lookup key while pointing at an inventory item. The default key is **G**; change it in Controls if needed.

Start with [Your first spaceflight](first_steps.md). Machine pages include rotatable construction examples and current recipes. Hover outlined parts to identify them. Use the [Holographic Projector](construction.md) to inspect layers while building.

Recipe panels follow the server's active recipes. **1,000 mB = one bucket**. Bucket pictures in processing panels identify the fluid, not the number of buckets required. Times and power costs are base values, before upgrades and server tuning.
