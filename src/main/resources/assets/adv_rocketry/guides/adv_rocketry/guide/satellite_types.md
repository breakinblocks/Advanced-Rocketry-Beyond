# Satellite types and terminals

Controller components determine the job. Optical sensors provide distance data, composition sensors provide composition data, and mass detectors provide mass data. Add adequate power and storage.

Insert a programmed chip in a Satellite Terminal. The terminal and satellite must share a planetary system. Transfer data into portable Item Data Storage units for research.

Ore Mapper satellites support the handheld Ore Scanner. Program the matching identifier and use the scanner to inspect nearby ore density. It helps prospect; it does not mine or deliver ore.

For asteroid work, use the [Observatory](observatory.md) and [Astrobody Data Processor](astrobody_data_processor.md).
