# Deploy and expand a station

Build a module on launch pads inside the Station Builder's scan area. Pack it, put the Space Station module in a rocket's Satellite Hatch, and launch for deployment.

The module occupies a persistent space cell. Use a programmed Station ID Chip for later visits. Establish landing pads, power and a sealed habitat.

To expand, give the existing and arriving module's Docking Ports matching labels. Deployment aligns ports by horizontal rotation or opposed vertical faces. Leave room for the incoming module.

The default station build radius is **1,024 blocks**; docking must stay within the configured boundary. Continue with [station controls](station_controls.md) and [warp](warp_travel.md).
