# Station controls

The Gravity Controller adjusts local station gravity toward a target. Test small changes safely. The Altitude Controller sets orbital distance, and the Orientation Controller sets rotation targets per axis. Orientation changes the view of space; anchored stations pause rotation.

Planet Selectors browse the star system and select a warp destination. The holographic selector also offers scale and redstone controls. Target selection still needs working [warp infrastructure](warp_travel.md).

Stop rotation and set a safe altitude and tilt before linking a [Space Elevator](space_elevator.md).
