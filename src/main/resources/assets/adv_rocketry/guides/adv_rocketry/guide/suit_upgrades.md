# Suit upgrades

Install modules in compatible armor slots at the Suit Workstation.

- **Jetpack:** uses hydrogen-filled chest tanks. Toggle with **X**, then hold jump to thrust.
- **Hover Upgrade:** with the helmet module installed, **Sneak + X** selects hover mode. It limits descent while consuming fuel.
- **Flight Speed Control Upgrade:** each helmet module increases horizontal jetpack speed by 2%, up to four modules.
- **Bionic Legs:** boost sprinting.
- **Padded Landing Boots:** prevent fall damage.
- **Anti-Fog Visor:** clears dense planetary fog.
- **Earthbright Visor:** restores daylight on dim or distant-star worlds.

Keys can be reassigned in Controls. Hydrogen does not replace breathing oxygen.
