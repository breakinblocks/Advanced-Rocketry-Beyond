# Warp travel and discovery

Place the controller on a station near a formed Warp Core. Supply FE and dilithium, select a reachable destination and check the displayed requirements.

The station remains in transit for a fuel-based travel time. Wait for arrival before using destination-specific services. Unlink a space elevator before attempting to warp an anchored station.

Destinations are visible by default. If discovery is required, research planets using distance, mass and composition data or import a programmed Planet ID Chip. Discoveries persist on the station; search odds are configurable.

Keep life support powered during travel.
